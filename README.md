## About me

I'm a software architect and backend engineer based in **Brasília, Brazil**, with over a decade of experience in software development.

I currently work at **Tribunal de Contas da União — TCU**, Brazil's Federal Court of Accounts. My work includes backend development, system modernization, and our internal developer portal, built with **Backstage**.

**Kotlin, Java, and Spring Boot** are at the core of my work. I also build developer tools and integrations, including **SAMUS**, a Backstage plugin for evaluating software component maturity.

I like understanding how systems work, documenting the decisions behind them, and writing code that the next developer can actually follow.

## What I work on

- **Backend engineering** — APIs, integrations, business rules, and batch processing.
- **Software architecture** — system design, modernization, ADRs, and technical documentation.
- **Developer experience** — developer portals, software catalogs, and tools that reduce repetitive work.
- **Reliability** — automated tests, observability, and CI/CD pipelines.
